HTML Text Formatting

Bold Makes Texts Bold.

strong Indicate that the text is important.

i Displays text in italic.

em Emphasize text.

u Underline text.

mark Highlight text.

small Display smaller text.

del Indicate deleted text.

ins Indicate inserted text.

sub Used to define subscription text.

sup Used to define Superscript text.
